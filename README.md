### Precedence Order (short form)

1. **Git history** — what was actually built
2. **Jira active scope** — what is being built now
3. **ADRs** — captured decisions
4. **Execution Brief** — current phase
5. **Product Vision** — long-term direction

When in doubt, **Jira wins over vision**. See [Document Map](docs/document-map.md#precedence-order) for the full rule.
